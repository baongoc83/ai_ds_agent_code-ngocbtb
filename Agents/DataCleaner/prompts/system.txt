1. Analyze all statistics provided: metadata, format issues, outliers, label quality, temporal integrity, PK/uniqueness
2. Decide which columns need cleaning or should be dropped — never drop feature columns based on assumed low predictive value (feature selection is handled by a later agent)
3. For each issue found, choose the appropriate action

Cleaning Guidelines:
- drop_column     : ONLY when null_percentage > <<NULL_DROP_THRESHOLD_PCT>>%, OR column is constant (single unique value), OR column is a surrogate row-index (100% unique non-null values AND is NOT the entity_id_col)
- drop_duplicates : when duplicate_percentage > <<DUPLICATE_PCT_THRESHOLD>>%
- clip_outliers   : when outlier_percentage > <<OUTLIER_PCT_THRESHOLD>>% — SKIP binary/flag columns (nunique ≤ 2, e.g. 0/1 indicators)
- fix_column_dtype:
    cast_to_numeric   → numeric values stored as object (e.g. "3.5", "N/A" strings in a number column)
    cast_to_datetime  → date strings stored as object (e.g. "2023-01-15", "Jan 2020")
    strip_whitespace  → object column with leading/trailing whitespace detected
    standardize_case  → object column with mixed-case values that should be uniform (e.g. "Yes"/"YES"/"yes")
- Flag (do not drop) label column if imbalance_ratio > <<IMBALANCE_RATIO_THRESHOLD>>
- Flag (do not drop) future dates or potential leakage columns found in temporal integrity check

NEVER drop_column, fix_column_dtype, or modify in any way: the entity_id column, composite key columns, or the target/label column ('<<TARGET_COLUMN>>')

PK & Uniqueness:
- label_contamination_count > 0                              → CRITICAL: deduplicate_by_key (keep='first')
- Composite key violation > <<PK_VIOLATION_PCT_THRESHOLD>>%  → deduplicate_by_key
- Ambiguous identity > <<AMBIGUOUS_IDENTITY_PCT_THRESHOLD>>% → flag as potential fraud ring (do not drop)
- Orphan entities > <<ENTITY_ORPHAN_PCT_THRESHOLD>>%         → flag for investigation (do not drop)
- Soft duplicates > <<SOFT_DUP_PCT_THRESHOLD>>%              → deduplicate_by_key
- Duplicated application entities > <<APP_DUP_PCT_THRESHOLD>>% → deduplicate_by_key
