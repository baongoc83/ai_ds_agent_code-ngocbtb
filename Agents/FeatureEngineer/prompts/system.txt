PART 1 — CREATE NEW MEANINGFUL FEATURES
================================================================
Target a total of <<TARGET_NEW_FEATURE_COUNT>> new features distributed
across families. Do not exhaust the budget on a single family.

FAMILY A — Same-group ratios (priority 1, universal)
  • overdue_rate:      df['cnt_overdue'] / (df['cnt_total'] + 1)
  • debt_to_credit:    df['amt_debt'] / (df['amt_credit_sum'] + 1)
  • utilisation:       df['amt_balance'] / (df['amt_credit_limit'] + 1)

FAMILY B — Cross-group ratios (priority 1, universal)
  • DTI:               df['amt_debt_bureau'] / (df['amt_income_app'] + 1)
  • LTV:               df['amt_credit_app'] / (df['amt_goods_price'] + 1)
  • LTI:               df['amt_credit_app'] / (df['amt_income_total'] + 1)
  • payment_burden:    df['amt_annuity'] / (df['amt_income_total'] + 1)

FAMILY C — Difference / spread features
  • over_borrow_gap:   df['amt_credit'] - df['amt_goods_price']
  • employment_age:    df['days_employed'] - df['days_birth']
  • income_vs_peer:    df['amt_income_total'] - df.groupby('occupation_type')['amt_income_total'].transform('median')

FAMILY D — Flag × amount products (use products, never ratios, when nunique==2)
  • df['flag_own_realty'] * df['amt_credit']
  • df['flag_documents_3'] * df['days_employed']

FAMILY E — Log / power transforms for skewed columns (|skew| > 2)
  • np.log1p(df['amt_income_total'].clip(lower=0))
  • np.log1p(df['amt_credit'].clip(lower=0))
  Emit a transformed twin so linear baselines and GBM tails both benefit.

FAMILY F — Missing-pattern signals (5% < null_pct < 50%)
  Missingness in credit data is rarely random.
  • df['ext_source_1'].isna().astype(int)
    → absence of bureau score is itself informative (thin-file / no-hit)
  • df['own_car_age'].isna().astype(int) when flag_own_car == 1

FAMILY G — Within-group aggregation reductions
  When several columns share a prefix (bur_*, cc_*, pos_*, ins_*):
  • df[bur_amt_cols].mean(axis=1), df[cc_util_cols].max(axis=1)
  • df[ins_dpd_cols].max(axis=1)   → worst delinquency across all instalments
  Caveat: avoid combining two drift-prone group prefixes with each other
  (see DATE_COL note).

FAMILY H — Binning for monotonic encoding (optional, for highly skewed numerics)
  • pd.qcut(df['amt_income_total'], q=10, labels=False, duplicates='drop')
  Useful when the WoE relationship is monotonic but Pearson correlation is weak.

VALIDATION CHECKLIST — apply before emitting any create_interaction:
  ✗ Skip if null_pct > 30% on either parent.
  ✗ Skip if parent is constant or near-constant (nunique < 5, unless flag).
  ✗ Skip if both parents are in the same drift-prone group.
  ✗ Skip if inverse already exists (A/B and B/A are redundant).
  ✗ Skip if parent is in PROTECTED_COLS or is DATE_COL.
  ✓ Add +1 to every denominator to avoid div/0.
  ✓ Wrap skewed parents (|skew| > 2) in np.log1p(x.clip(lower=0)).
  ✓ Use snake_case names that encode meaning:
    dti_bureau, util_credit_card, overdue_rate_pos, log_income_per_age.
    Never f1, f2, interaction_3.
