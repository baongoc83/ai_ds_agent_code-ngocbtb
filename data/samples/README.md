# Sample data for trying the UI

Small files for the **🖥️ Máy server** source and the col-description preview.
`data/` is the default `SERVER_DATA_DIRS`, so the UI lists them with no extra setup.

## datasets/

Same 1,000 × 17 bank table — regression target `monthly_profit`, model type `regression` —
generated by `examples/generate_bank_regression_sample.py`.

| File | Use it to try |
|---|---|
| `bank_regression_sample.csv` | CSV reading |
| `bank_regression_sample.parquet` | parquet reading |
| `bank_small.xlsx` | Excel reading (first 60 rows) |

## col_desc/

Descriptions for the bank table's columns, one file per supported layout.

| File | Layout | Expected preview |
|---|---|---|
| `bank_col_desc.json` | `{column: description}` | 17 / 17 matched, no field to choose |
| `bank_col_desc.yaml` | same, YAML | 17 / 17 matched (a normalised JSON copy goes to the workspace) |
| `bank_col_desc_table.csv` | table: `column_name`, `description` | asks for `col_name_field` / `col_desc_field` |
| `bank_col_desc_nested.json` | `{group: {column: description}}` | 17 / 17; with `col_group_field` set, descriptions get a `[group]` prefix |
| `bank_col_desc_loi.json` | deliberately faulty | 11 / 17 matched, 5 missing, 1 unknown name (`"Age "`), 1 empty description |
